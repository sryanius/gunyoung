## 1. 조종 선택 (sim + 화면)

- sim API 추가: `b.setPlayer(side, generalId | null)` — 그 편의 조종 무장을 바꾼다. `null` = 전원 AI(자동). 바꾸는 순간 이전 조종 무장은 AI 로 돌아가고 입력 벡터는 0 으로. `b.playerOf(side)` 는 현재 값을 돌려준다. 결정성 유지(같은 seed·같은 호출 순서 = 같은 결과), 벤치 기준 그대로 통과.
- 조종 중인 무장이 죽으면: 살아 있는 다른 아군 무장으로 자동 전환(수동 유지), 없으면 자동.
- 화면:
  - HUD 의 **아군 무장 초상을 탭** = 그 무장을 조종(테두리 금색 강조 + 「조종」 작은 표식). 이미 조종 중인 초상을 다시 탭 = 자동으로.
  - **「자동/수동」 토글 버튼**(병법 버튼 줄 왼쪽): 자동이면 전원 AI — 무장기도 AI 가 쓴다. 자동 중에도 카메라는 마지막으로 고른 무장을 따라가고, 무장기 버튼을 누르면 그 무장의 무장기를 직접 쓸 수 있다(게이지 100 일 때).
  - 자동일 때 조이스틱은 안 생긴다. 조이스틱을 쓰려고 왼쪽을 드래그하면 「수동으로 전환」 토스트 없이 그냥 수동으로 돌아온다(마지막 고른 무장).
  - 무장기 버튼의 아이콘·이름·게이지는 **현재 고른 무장** 것으로 바뀐다(장비면 포효).
  - 키보드: Tab = 다음 무장, Q = 자동/수동.
  - 기존 「입력 없을 때 부대 따라가기」는 수동에서만.

## 2. 배속

- HUD 오른쪽 위(시간 옆)에 **배속 버튼**: 탭할 때마다 1× → 2× → 3× → 1×. 글자 「×1」「×2」「×3」(붓글씨 말고 본문 폰트 굵게).
- 구현: BattleScene.update 에서 sim 에 넘기는 시간에 배율을 곱한다. 고정 틱(16.7ms) 누적기라 결정성은 그대로. 프레임당 step 호출 상한을 배율만큼 늘려라(≤50ms × ≤4×배율).
- 화면 연출 타이머(걷기 bob·깃발 등 `animT`)도 같이 빨라진다. **컷인·히트스톱·결과 패널 트윈은 실시간 그대로**(컷인이 3배로 지나가면 보이지 않는다).
- 배속은 `registry` 에 기억해 다음 전투에도 유지. 전투 인트로 중에는 배속 무시.
- 키보드: 1/2/3 은 병법이라 배속은 `+`/`-` 또는 `X`.

### 3.3 컷신 연출 (코드 — `src/battle/cutin.js` 신설, fx.js 의 컷인이 이걸 부른다)

총 1.6초(실시간, 배속 무관). sim 은 그동안 멈춘다(히트스톱 확장 — 기존 120ms 대신 컷신 길이만큼. 무장기 피해 이벤트는 컷신이 끝나는 순간 터지는 것처럼 보이게: 피해 연출(파동·링·넉백 회전)은 컷신 종료 시점에 재생).

1. **0.00~0.25s 암전+눈 띠**: 화면 전체 어둡게(알파 0.6), `<key>_eyes` 띠가 화면 가운데를 가로로 가르며 빠르게 열린다(세로 0→180px, 좌우 페이드, 살짝 줌). 효과음 「슥」.
2. **0.25~1.20s 주 일러스트**: 화면을 가르는 **사선 패널**(무장 색 그라데이션 + 금테, 기울기 −12°) 위로 주 일러스트가 오른쪽(적은 왼쪽)에서 미끄러져 들어와 감속하며 멈춘다(마스크로 패널 안에만 보임). 배경은 speedlines 회전 + 무장 색 입자(ADD). 일러스트는 멈춘 뒤에도 천천히 1.00→1.06 줌(살아 있는 느낌). 림 라이트처럼 밝은 가산 복사본을 살짝 어긋나게 겹친다.
3. **0.45s~ 이름·무장기명**: 반대편에 붓글씨 — 이름(64px, 흰색+검은 외곽)과 무장기명(96px, 금색 그라데이션, 한 글자씩 0.05s 간격으로 찍히며 흔들림). 먹물 번짐 자국(Graphics) 위에.
4. **1.20~1.45s 발동**: 흰 플래시 → 패널이 위아래로 갈라지며 닫힘, 카메라 줌 펀치 1.25, 흔들림.
5. **1.45~1.60s**: 전장으로 복귀, 그 순간 피해 연출 재생.
- 에셋이 없으면(눈 띠·일러스트) 그 박자를 건너뛰고 붓글씨만.
- 같은 무장기가 연달아 터질 때(1.6초 안) 두 번째는 0.6초 짧은 버전(눈 띠 생략).
- 설정: `registry.cutinMode` = 'full' | 'short' | 'off' — HUD 에 넣지는 말고 코드 상수로(다음에 옵션 화면에서).
